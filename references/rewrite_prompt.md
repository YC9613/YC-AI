# 豆包式文案改写规则

根据来源链接、标题和完整文案，生成结构完整、表达独立的简体中文口播稿。

## 写作规则

1. 先锁定原文中的人物、时间、地点、数字、事件、因果关系、论据和结论。
2. 完整讲清原文内容，不能写成摘要、导语或提纲。
3. 正文有效信息量不得低于输入完整文案的 90%；90% 是最低门槛，不代表复制原句。
4. 重新组织标题、开头、主语、句式、段落顺序、连接方式和口播节奏。
5. 根据内容选择合适的表达角度，避免标题、开头、事实顺序、转场和结尾重复。
6. 不新增原文没有的人名、日期、数字、案例、数据或结论。
7. 使用简体中文和自然的口播表达，正文不使用小标题、编号或 Markdown 标记。
8. 不做简单同义词替换，不复制原文句式，不输出改写过程说明。

## 输出格式

只输出合法 JSON：

```json
{
  "versions": [
    {
      "angle": "内容角度",
      "title": "改写标题",
      "body": "完整改写正文"
    }
  ]
}
```
